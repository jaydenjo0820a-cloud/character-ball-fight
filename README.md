# 캐릭터 볼 파이트

Python이 설치된 환경에서 프로젝트 폴더의 `server.py`를 실행한 뒤 `http://localhost:4000`에 접속하세요.

```powershell
python server.py
```

플레어, 프로스트, 공기청정기 중 캐릭터를 골라 자동 대전을 진행합니다. 공기청정기는 1초마다 상대에게 8 피해를 주고, 15초마다 자신을 100 회복시키며 상대에게 100 피해를 주는 스킬을 사용합니다. 캐릭터 카드의 정보 메뉴에서 패시브와 스킬 설명을 확인할 수 있습니다. 바람 아이콘과 먼지바람 스킬 그림은 `assets`에서 불러오며, 패시브 윙윙 소리와 스킬 whoosh 효과음도 별도 WAV 파일로 재생합니다.
